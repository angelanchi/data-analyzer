# Data Analyzer - 電子測試數據分析平台

**作者**: An9

**最後更新**: 2025-01-22
**狀態**: 已實作

## 1. 產品概述

### 1.1 產品定位
Data Analyzer 是一個專為電子製造業設計的Web端數據分析平台，專注於處理FPC（柔性電路板）批次測試數據。系統提供完整的數據處理工作流程，從資料上傳、清理、多維度檢視、可視化到結果匯出。

### 1.2 目標用戶
- **品質工程師**: 進行批次測試數據分析和品質控制
- **製程工程師**: 監控生產線設備性能和參數趨勢
- **研發人員**: 進行實驗數據分析和統計驗證
- **實驗室技術人員**: 生成測試報告和數據可視化

### 1.3 核心價值
- **簡化數據處理流程**: 5步驟完成從上傳到匯出的完整分析
- **智能化推薦**: 根據數據特性自動推薦適用的圖表類型
- **多維度檢視**: 支援逐筆資料檢視（含排序）、分組彙總檢視兩種模式
- **指標智能分類**: 自動區分數值型與字串型指標，提供精準的分析選項
- **專業化分析**: 針對電子測試數據的特殊需求優化
- **完整匯出結構**: 一次匯出包含資料總覽、詳細數據、統計資訊的完整報告

## 2. 功能需求

### 2.1 數據上傳 (FR-001)

#### 功能描述
支援批次上傳CSV和Excel格式的測試數據檔案

#### 詳細需求
- **FR-001-01**: 支援拖拽上傳介面
- **FR-001-02**: 支援CSV (.csv)、Excel (.xls, .xlsx) 格式
- **FR-001-03**: 單檔案大小限制: 50MB
- **FR-001-04**: 顯示上傳進度指示器
- **FR-001-05**: 自動偵測檔案編碼 (UTF-8, Big5)
- **FR-001-06**: 上傳後即時預覽數據（前5-10列）
- **FR-001-07**: 顯示數據基本統計資訊（行數、欄位數、欄位類型）

#### 資料格式規範
系統接受包含以下欄位的電子測試數據（不強制所有欄位都存在）:

**識別欄位**:
- **唯一識別碼** (可配置):
  - 系統預設支援 `Point_ID`、`PointId`、`point_id` 自動偵測
  - **可自訂任何欄位**作為唯一識別碼（例如：`Sample_ID`、`Test_ID`、`Serial_Number`）
  - 支援自動生成模式：當指定欄位不存在時，系統可自動生成唯一ID
  - 生成格式可自訂（預設：`{source}_P{index}`，例如 `Batch1_P001`）
  - 配置方式：在「數據格式設置類型」步驟中設定
- `Source_File`: 來源檔案名稱（系統自動添加）

**位置資訊**:
- `Location_X`: X座標
- `Location_Y`: Y座標

**電子參數** (數值型):
- `Voltage`: 電壓
- `Current`: 電流
- `Temperature`: 溫度
- `Resistance`: 電阻
- `Capacitance`: 電容
- `Power`: 功率
- `Frequency`: 頻率
- `Impedance`: 阻抗
- `Phase_Angle`: 相位角
- `Signal_Quality`: 訊號品質

**測試資訊** (分類型):
- `Test_Time`: 測試時間
- `Operator`: 操作員
- `Equipment_ID`: 設備ID
- `Batch_No`: 批次號
- `Test_Result`: 測試結果 (PASS/Fail/Warning)

### 2.2 唯一識別碼配置 (FR-002)

#### 功能描述
提供靈活的唯一識別碼欄位配置，適應不同數據格式的需求

#### 詳細需求

**FR-002-01: 欄位選擇**
- 自動偵測模式（預設）:
  - 系統自動搜尋 `Point_ID` → `PointId` → `point_id`
  - 向後相容舊版數據格式
  - 若全部不存在則自動生成
- 自訂欄位模式:
  - 使用者可從分類欄位列表選擇任意欄位
  - 適用於使用 `Sample_ID`、`Test_ID`、`Serial_Number` 等自訂識別碼的數據
  - 支援所有分類型欄位

**FR-002-02: 自動生成設定**
- 啟用/停用開關:
  - 啟用時：當指定欄位缺失或為空時自動生成ID
  - 停用時：欄位缺失時回退到自動偵測邏輯
- 生成格式自訂:
  - 預設格式：`{source}_P{index}`（例如：`Batch1_P001`）
  - 支援變數：`{source}` (來源檔案名)、`{index}` (記錄序號)
  - 範例：`Sample_{index}` → `Sample_1`, `Sample_2`...

**FR-002-03: 配置介面**
- 下拉式選單顯示所有可用分類欄位
- 視覺化狀態提示:
  - 自動偵測模式：顯示綠色成功提示，說明偵測規則
  - 自訂模式：顯示藍色資訊提示，顯示選定欄位
- 即時預覽選擇結果

**FR-002-04: 系統整合**
- 自動更新數據檢視模式的識別碼欄位
- 自動調整圖表推薦邏輯使用選定的識別碼
- 自動從統計分析中排除識別碼欄位
- 確保向後相容性

### 2.3 數據清理 (FR-003)

#### 功能描述
提供視覺化的數據清理工具，處理缺失值、異常值和數據範圍過濾

#### 詳細需求

**FR-002-01: 缺失值處理**
- 支援三種處理策略:
  - 刪除包含缺失值的記錄
  - 填入預設值（0, 均值, 中位數）
  - 使用插值法（線性插值）
- 顯示每個欄位的缺失值數量和比例

**FR-003-02: 異常值檢測**
- 支援兩種檢測方法:
  - IQR (Interquartile Range) 方法
  - Z-Score 方法
- 可設定敏感度參數
- 高亮顯示異常值

**FR-003-03: 數值範圍過濾**
- 為數值型欄位設定最小/最大值
- 自動顯示數據分佈範圍建議
- 即時顯示保留數據比例

**FR-003-04: 預覽功能**
- 顯示清理前後數據對比
- 顯示清理統計資訊（移除記錄數、保留比例）
- 支援重置清理規則

### 2.4 數據檢視模式 (FR-004)

#### 功能描述
提供兩種數據檢視模式，適應不同的分析需求

#### FR-004-01: 逐筆資料檢視 (Flattened Data View)
- **用途**: 保留所有原始記錄，支援排序，適合詳細分析和匯出到外部工具
- **觸發條件**: 未選擇分組欄位時自動啟用
- **特性**:
  - 維持與原始數據相同的行數
  - 包含唯一識別碼、Source_File 識別欄位
  - 包含所有選定的字串指標和數值指標
  - **支援主要排序與次要排序**
- **輸出欄位**: `[唯一識別碼, Source_File, 字串指標..., 數值指標...]`
- **排序功能** (NEW):
  - **主要排序**: 選擇一個字串指標作為第一層排序依據
  - **次要排序**: 選擇另一個字串指標作為第二層排序依據
  - 排序在匯出時套用，確保數據有序排列
  - 適合匯出到 Minitab、MATLAB 等分析工具

#### FR-004-02: 分組彙總檢視 (Grouped Data View)
- **用途**: 按選定欄位聚合，產生統計摘要
- **觸發條件**: 選擇一個或多個分組欄位時自動啟用
- **特性**:
  - 依所選分組欄位組合產生群組
  - 對每個數值指標計算統計量
  - 適合批次比較和趨勢分析
  - 僅對數值型指標進行聚合運算
- **輸出欄位**: `[分組欄位..., metric_mean, metric_count, metric_min, metric_max, metric_sum]`
- **統計指標**:
  - `_mean`: 平均值
  - `_count`: 數量
  - `_min`: 最小值
  - `_max`: 最大值
  - `_sum`: 總和

#### FR-004-03: 指標分類系統 (NEW)
- **數值指標 (Numeric Metrics)**:
  - 用於統計計算和聚合運算
  - UI 顯示為藍色 chip
  - 可作為圖表 Y 軸
  - 包含：Voltage, Current, Temperature, Resistance 等
- **字串指標 (Categorical Metrics)**:
  - 用於分組、排序和標籤
  - UI 顯示為橘色 chip
  - 可作為圖表 X 軸或圖例分組
  - 包含：Batch_No, Operator, Equipment_ID, Test_Result 等

#### FR-004-04: 檢視模式自動切換
- 系統根據使用者選擇的分組欄位自動切換檢視模式
- 未選擇分組欄位 → 逐筆資料檢視
- 選擇分組欄位 → 分組彙總檢視
- 即時預覽前 5-10 行數據
- 顯示行數統計資訊

### 2.5 圖表生成 (FR-005)

#### 功能描述
提供三種專業圖表類型，支援智能推薦和自訂配置

#### FR-005-01: 散點圖 (Scatter Plot)
- **引擎**: Plotly.js
- **適用場景**: 相關性分析、趨勢檢測、異常值識別
- **配置選項**:
  - X軸: 任意數值欄位
  - Y軸: 任意數值欄位
  - 分組: 可選分類欄位（以顏色區分）
  - 標題、軸標籤自訂
- **互動功能**:
  - 縮放、平移
  - 懸停顯示數值
  - 下載為PNG/SVG

#### FR-005-02: 線性圖 (Line Chart)
- **引擎**: Chart.js
- **適用場景**: 時間序列、變化趨勢、多組數據比較
- **配置選項**:
  - X軸: 序列型或時間型欄位
  - Y軸: 一個或多個數值欄位
  - 分組: 可選（產生多條線）
- **特性**:
  - 支援多Y軸
  - 平滑曲線選項
  - 數據點標記

#### FR-005-03: 點圖/柱狀圖 (Dot/Bar Plot)
- **引擎**: Chart.js
- **適用場景**: 類別比較、批次對比、分組分析
- **配置選項**:
  - X軸: 分類欄位
  - Y軸: 數值欄位
  - 圖表型態: 垂直/水平柱狀圖
- **特性**:
  - 支援堆疊模式
  - 支援分組柱狀圖
  - 數值標籤顯示

#### FR-005-04: 智能推薦系統
- 根據數據特性自動分析適用性:
  - 檢查X/Y軸數據類型
  - 分析數據分佈
  - 評估記錄數量
- 推薦圖表時顯示「Recommended」標籤
- 不改變圖表顯示順序（固定為 Scatter → Line → Bar）

### 2.6 數據匯出 (FR-006)

#### FR-006-01: 統一匯出 API (NEW)
- **端點**: `POST /api/export/data`
- **特性**: 一次匯出完整的數據結構
- **參數**:
  - flattenedData: 逐筆數據（已排序）
  - groupedData: 分組彙總數據（如有）
  - metadata: 批次檢視元資訊
  - primarySort, secondarySort: 排序欄位
  - includeStatistics: 是否包含統計資訊

#### FR-006-02: Excel 格式 (多工作表結構)
- **Sheet 1: Data Overview** (資料總覽)
  - Batch Count: 批次數量
  - Total Flattened Rows: 逐筆數據總行數
  - Total Grouped Points: 分組數據點數
  - Flatten Params: 數值指標列表
  - Group Params: 分組欄位列表
  - Default Metrics: 預設指標
  - Default Groups: 預設分組

- **Sheet 2: Flattened Data - Sorted** (逐筆數據 - 已排序)
  - 所有原始記錄
  - 已套用主要/次要排序
  - 包含唯一識別碼、Source_File、所有選定指標

- **Sheet 3: Grouped Data** (分組彙總數據)
  - 僅在選擇分組欄位時包含
  - 分組欄位 + 聚合統計（mean, count, min, max, sum）

- **Sheet 4: Statistics** (統計資訊)
  - 僅在勾選「包含摘要統計」時包含
  - 每個數值指標的完整統計量
  - Field, Mean, Median, Std, Min, Max, Count

#### FR-006-03: CSV 格式 (分段式結構)
- **編碼**: UTF-8 with BOM（相容 Excel、Minitab、MATLAB）
- **結構**:
  ```
  === Data Overview ===
  Batch Count,3
  Total Flattened Rows,188
  ...

  === Flattened Data - Sorted ===
  唯一識別碼,Source_File,Voltage,Current,...
  P001,Batch1,5.2,0.15,...
  ...

  === Grouped Data ===
  Batch_No,Voltage_mean,Voltage_count,...
  B001,5.25,50,...
  ...

  === Statistics ===
  Field,Mean,Median,Std,Min,Max,Count
  Voltage,5.215,5.20,0.15,4.9,5.5,188
  ...
  ```

#### FR-006-04: 圖表匯出 (前端處理)
**PNG格式**
- 支援所有圖表類型
- 可調整解析度（scale 參數）
- 可自訂背景色
- 自訂檔案名稱
- **實作**: Plotly.js 原生 `downloadImage()`、Chart.js `canvas.toBlob()`

**SVG格式**
- 僅支援 Plotly 圖表（Scatter）
- 向量格式，無損縮放
- 適合用於文件和簡報
- **實作**: Plotly.js 原生 `downloadImage()`

**技術實作**:
- 完全在前端處理，無需後端 API
- 使用 `frontend/src/utils/chartExport.ts`
- 直接訪問 DOM 和 Canvas，性能更佳

#### FR-006-05: 匯出介面
- 卡片式選項設計，Excel 優先顯示
- 圖示化格式識別
- 匯出前預覽設定
- 錯誤處理和使用者回饋
- 下載連結自動開啟

## 5. 使用流程

### 5.1 標準分析工作流程
```
1. 上傳資料
   ↓
2. 資料清理（可選）
   ↓
3. 數據格式設置
   ├─ 選擇數值指標（藍色 chip）
   ├─ 選擇字串指標（橘色 chip）
   ├─ 選擇分組欄位（觸發分組彙總檢視）
   ├─ 設定主要排序（用於逐筆檢視）
   └─ 設定次要排序（用於逐筆檢視）
   ↓
4. 資料檢視預覽
   ├─ 無分組 → 逐筆資料檢視（所有原始記錄）
   └─ 有分組 → 分組彙總檢視（聚合統計）
   ↓
5. 建立圖表
   ├─ 選擇圖表類型（Scatter/Line/Bar）
   ├─ 配置 X 軸、Y 軸
   ├─ 配置圖例分組（可選）
   └─ 預覽結果
   ↓
6. 匯出結果
   ├─ 數據匯出（Excel 多工作表 / CSV 分段式）
   └─ 圖表匯出（PNG / SVG）
```

### 5.2 使用場景範例

**場景1: FPC批次品質分析**
1. 上傳多個批次 CSV 檔案
2. 清理異常數據（移除 Test_Result = Fail 的記錄）
3. 數據格式設置：
   - 數值指標：Voltage, Current, Temperature
   - 字串指標：Batch_No, Equipment_ID, Operator
   - 分組欄位：Batch_No, Equipment_ID
4. 系統自動切換至分組彙總檢視
5. 建立柱狀圖，X 軸 = Batch_No，Y 軸 = Voltage_mean
6. 匯出 Excel 多工作表報告（包含統計資訊）和 PNG 圖表

**場景2: 設備性能追蹤**
1. 上傳時間序列測試數據
2. 不進行清理
3. 數據格式設置：
   - 數值指標：Temperature, Voltage
   - 字串指標：Test_Time, Equipment_ID
   - 不選擇分組欄位（觸發逐筆檢視）
   - 主要排序：Test_Time
4. 系統自動切換至逐筆資料檢視
5. 建立線性圖，X 軸 = Test_Time，Y 軸 = Temperature，圖例分組 = Equipment_ID
6. 匯出 SVG 向量圖用於報告

**場景3: 結構化資料整理給外部工具**
1. 上傳原始測試數據
2. 簡單清理（填充缺失值）
3. 數據格式設置：
   - 數值指標：Voltage, Current, Resistance
   - 字串指標：Batch_No, Operator, Test_Result
   - 不選擇分組欄位
   - 主要排序：Batch_No
   - 次要排序：Operator
4. 系統自動切換至逐筆資料檢視（已套用排序）
5. 不建立圖表
6. 直接匯出 CSV 給 Minitab 進一步分析（數據已按 Batch_No → Operator 排序）

## 附錄

### A. 術語表
- **FPC**: 柔性電路板 (Flexible Printed Circuit)
- **批次數據**: 同一生產批次的測試數據集合
- **逐筆資料檢視**: 保持原始記錄結構不變，支援排序
- **分組彙總檢視**: 將多筆記錄按分組欄位合併計算統計量
- **數值指標**: 可進行統計運算的數值型欄位（Voltage, Current 等）
- **字串指標**: 用於分類、分組和標籤的文字型欄位（Batch_No, Operator 等）
- **主要/次要排序**: 兩層級欄位排序，先按主要欄位排序，再按次要欄位排序
- **圖例分組**: 在圖表中以不同顏色/標記區分不同類別的功能
