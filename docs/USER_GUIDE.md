## 快速開始

### 系統需求

- 現代化瀏覽器：Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- 穩定的網路連線
- 支援的數據格式：CSV（UTF-8）、Excel（.xlsx）

### 首次使用

1. 開啟瀏覽器並訪問應用程式 URL（預設：`http://localhost:3000`）
2. 您會看到一個 5 步驟的數據分析工作流程
3. 準備好您的電子測試數據檔案（CSV 或 Excel 格式）
4. 依照步驟完成數據上傳、清理、設置、可視化和匯出

## 完整工作流程

Data Analyzer 提供一個直覺的 5 步驟工作流程，引導您完成從數據上傳到結果匯出的整個過程。

### 步驟 1: 數據上傳 📁

#### 支援格式
- **CSV 檔案**：建議使用 UTF-8 編碼
- **Excel 檔案**：支援 .xlsx 格式（不支援 .xls）

#### 操作步驟
1. 點擊「選擇檔案」或拖曳檔案到上傳區域
2. 可以一次上傳多個檔案（支援批次上傳）
3. 系統會自動為每個檔案添加 `Source_File` 欄位以便識別來源
4. 上傳完成後，點擊「下一步」進入清理階段

#### 注意事項
- 單個檔案建議不超過 50MB
- 確保檔案包含欄位標題行（第一行）
- 日期格式建議使用 ISO 8601（YYYY-MM-DD）

#### 範例數據格式
```csv
Point_ID,Location_X,Location_Y,Voltage,Current,Temperature,Test_Result,Batch_No
P001,10.5,20.3,5.2,0.15,25.3,PASS,B001
P002,11.2,21.1,5.3,0.16,25.5,PASS,B001
P003,10.8,20.9,4.9,0.14,26.1,Fail,B001
```

### 步驟 2: 數據清理 🧹

數據清理是確保分析質量的關鍵步驟，系統提供三大清理功能。

#### 2.1 缺失值處理

**刪除含有缺失值的列**
- 適用場景：當缺失值比例很小（<5%）且不影響整體分析
- 操作：選擇「Remove rows with missing values」
- 注意：會永久移除這些列

**插值填充**
- 適用場景：數值型欄位的缺失值，且數據具有連續性
- 方法：使用線性插值算法
- 操作：選擇「Interpolate missing values」
- 限制：只適用於數值型欄位

**預設值填充**
- 適用場景：類別型欄位或固定值填充
- 操作：選擇「Fill with default value」並輸入填充值
- 範例：將 Test_Result 的缺失值填充為 "Unknown"

#### 2.2 異常值檢測

**IQR 方法（四分位距）**
- 原理：偵測超出 Q1 - 1.5×IQR 或 Q3 + 1.5×IQR 範圍的值
- 適用場景：數據大致呈常態分佈
- 操作步驟：
  1. 選擇「IQR Method」
  2. 選擇要檢測的數值欄位（如 Voltage, Current）
  3. 點擊「Apply」執行檢測
  4. 查看清理後的數據筆數

**Z-Score 方法**
- 原理：偵測距離平均值超過 ±3 個標準差的值
- 適用場景：數據嚴格符合常態分佈
- 操作步驟：
  1. 選擇「Z-Score Method」
  2. 設定閾值（預設為 3）
  3. 選擇要檢測的數值欄位
  4. 點擊「Apply」執行檢測

#### 2.3 數值範圍過濾

- 用途：設定欄位的最小/最大值範圍
- 操作：
  1. 選擇「Value Range Filter」
  2. 選擇目標欄位
  3. 輸入最小值和最大值
  4. 點擊「Apply」

#### 即時預覽

清理過程中，系統會顯示：
- 清理前數據筆數
- 清理後數據筆數
- 被移除的數據筆數
- 清理操作摘要

**重要提示**：清理操作是累積的，每次清理都會基於上一次的結果。建議先預覽效果再進行下一步。

### 步驟 3: 資料參數設定 ⚙️

這是新增強的步驟，讓您精確控制數據的呈現方式。

#### 3.1 數值指標選擇

**用途**：選擇要分析的數值型欄位

**說明**：
- 這些欄位會被彙總計算統計量（平均值、最小值、最大值等）
- 在圖表中作為 Y 軸數據
- 支援多選

**範例**：選擇 `Voltage`、`Current`、`Temperature` 作為數值指標

**標示**：選中的欄位會顯示藍色「數值」標籤

#### 3.2 字串指標選擇

**用途**：選擇對應數值的項目名稱欄位

**說明**：
- 這些欄位會出現在數據輸出和圖表配置選項中
- 通常是用於標識或分類的文字欄位
- 可作為圖表的 X 軸選項或圖例分組依據
- 支援多選

**範例**：選擇 `Operator`、`Equipment_ID`、`Batch_No`、`Source_File`

**標示**：選中的欄位會顯示橘色「字串」標籤

**自動選擇**：系統會自動選擇 `Source_File`（檔案來源識別欄位）

#### 3.3 分組欄位設定（選填）

**用途**：決定數據是否要進行分組彙總

**兩種模式**：

**模式 A：不選擇分組欄位（逐筆數據）**
- 數據以逐筆方式呈現，顯示所有原始數值
- 適合詳細分析和完整數據檢視
- 匯出時會包含所有選定的數值指標和字串指標

**模式 B：選擇分組欄位（分組彙總）**
- 數據依選定欄位分組，產生統計數據
- 每組顯示數值指標的統計量（平均值、計數、最小值、最大值）
- 適合趨勢分析和摘要報告
- 範例：按 `Batch_No` 分組，可看到每批次的平均電壓、電流等

**分組提示**：
- 系統會顯示當前分組設定和產生的分組數量
- 如果包含 `Point_ID` 分組，等同於逐筆資料（每筆視為獨立分組）

#### 3.4 排序設定（選填）

**用途**：設定資料的排序順序，用於預覽和匯出

**主要排序欄位**：
- 從已選擇的數值指標和字串指標中選擇
- 數據會優先依此欄位排序（升序）
- 可顯示欄位類型標籤（藍色「數值」或橘色「字串」）

**次要排序欄位**：
- 在主要排序值相同時，依此欄位排序
- 只有設定主要排序後才能設定次要排序
- 無法選擇與主要排序相同的欄位

**排序範例**：
- 主要：`Batch_No`（字串）
- 次要：`Temperature`（數值）
- 結果：先按批次號排序，同批次內按溫度排序

**排序預覽**：
- 資料預覽區會顯示排序資訊（如：「排序依據：Batch_No → Temperature」）
- 匯出的數據會自動應用此排序

#### 資料預覽

設定完成後，系統會顯示：
- **預覽標題**：顯示檢視類型（逐筆資料檢視 或 分組資料檢視）
- **欄位列表**：顯示所有輸出欄位
- **選取指標**：顯示選定的數值指標
- **前 5 列數據**：快速預覽數據格式
- **排序資訊**：如有設定排序，會顯示排序欄位

### 步驟 4: 圖表配置與預覽 📊

選擇適合的圖表類型來視覺化您的數據。

#### 4.1 圖表類型

**散點圖（Scatter Plot）** - 使用 Plotly.js
- **適用場景**：觀察兩個數值變數之間的相關性
- **X 軸**：數值型欄位
- **Y 軸**：數值型欄位
- **圖例分組**：可選擇字串指標作為分組依據，以不同顏色顯示
- **範例**：X 軸選 Location_X，Y 軸選 Voltage，按 Batch_No 分組

**折線圖（Line Chart）** - 使用 Chart.js
- **適用場景**：觀察數值隨類別或時間的變化趨勢
- **X 軸**：字串型欄位（從已選擇的字串指標中選擇）
- **Y 軸**：數值型欄位
- **圖例分組**：可選擇其他字串指標作為數據系列
- **範例**：X 軸選 Point_ID，Y 軸選 Temperature，按 Operator 分組

**長條圖（Bar Chart）** - 使用 Chart.js
- **適用場景**：比較不同類別的數值大小
- **X 軸**：字串型欄位（從已選擇的字串指標中選擇）
- **Y 軸**：數值型欄位
- **圖例分組**：可選擇其他字串指標進行分組比較
- **範例**：X 軸選 Equipment_ID，Y 軸選 Current，按 Test_Result 分組

#### 4.2 圖表配置

點擊圖表類型卡片後，會開啟配置對話框：

1. **圖表標題**：輸入描述性標題（必填）
2. **X 軸選擇**：選擇 X 軸數據欄位（必填）
3. **Y 軸選擇**：選擇 Y 軸數據欄位（必填）
4. **圖例分組（選填）**：
   - 選擇此欄位後，資料會依此分組
   - 以不同顏色/標記顯示在圖表中作為圖例
   - 範例：按 `Operator` 分組，每個操作員的數據會以不同顏色顯示

**重要**：
- X 軸和 Y 軸選項只會顯示在步驟 3 選擇的字串指標和數值指標
- 圖例分組選項也只會顯示選定的字串指標
- 這確保圖表配置與數據設定一致

#### 4.3 圖表預覽

配置完成後：
- 圖表會立即渲染並顯示
- 可進行互動操作（縮放、懸停查看數值等）
- 如需修改，點擊「重新配置」

#### 4.4 跳過圖表（選填）

- 圖表配置步驟是**可選的**
- 即使不繪製圖表，也可以直接進入下一步匯出數據
- 適合只需要數據整理而不需要視覺化的場景

### 步驟 5: 匯出結果 💾

將處理完成的數據和圖表匯出，供後續使用。

#### 5.1 數據匯出

系統提供兩種格式，匯出內容會自動包含完整的數據結構。

**Excel 活頁簿（.xlsx）** - 推薦格式
- **優點**：
  - 多分頁組織，結構清晰
  - 保留欄位型別
  - 自動調整欄寬
  - 支援中文字元
- **分頁結構**：
  1. **Data Overview**（資料總覽）- 總是包含
     - 摘要資訊（批次數、總列數、欄位統計）
     - 來源檔案清單
     - 前 15 列資料預覽
     - 整體統計數據（每個數值指標的平均值、計數、最小值、最大值）
     - 每個來源檔案的統計數據
  2. **逐筆數據（已排序）**- 總是包含
     - 包含所有選定的數值指標和字串指標
     - 已應用步驟 3 設定的排序
     - 如有排序，分頁名稱會顯示「(已排序)」
  3. **分組彙總數據** - 如果步驟 3 有選擇分組欄位
     - 依分組欄位產生的統計數據
     - 包含各組的平均值、計數等
  4. **統計信息** - 如果勾選「包含摘要統計」
     - 詳細的統計資訊
     - 每個欄位的描述性統計

**CSV 檔案（.csv）**
- **優點**：
  - 相容於 Excel、Minitab、MATLAB 等多數工具
  - 檔案較小
  - 純文字格式，易於處理
- **內容結構**（以區塊分隔）：
  1. `=== DATA OVERVIEW ===`
  2. `=== 逐筆數據 (排序：欄位名) ===`
  3. `=== 分組彙總數據 ===`（如有）
  4. `=== 統計信息 ===`（如勾選）
- **編碼**：UTF-8 with BOM（確保 Excel 正確顯示中文）

#### 5.2 匯出設定

開啟匯出對話框後：

1. **檔案名稱**：輸入匯出檔名（自動生成時間戳記）
2. **包含摘要統計**：勾選後會在匯出檔案中包含詳細統計資訊（預設勾選）
3. **點擊「開始匯出」**

#### 5.3 匯出範例

**範例情境 1：逐筆數據 + 排序**
- 步驟 3 設定：
  - 數值指標：Voltage, Current
  - 字串指標：Point_ID, Batch_No
  - 分組欄位：無
  - 排序：主要 Batch_No，次要 Voltage
- 匯出結果（Excel）：
  - 分頁 1：Data Overview
  - 分頁 2：逐筆數據 (已排序) - 包含 Point_ID, Batch_No, Voltage, Current，按 Batch_No → Voltage 排序
  - 分頁 3：統計信息（如勾選）

**範例情境 2：分組彙總數據**
- 步驟 3 設定：
  - 數值指標：Voltage, Current, Temperature
  - 字串指標：Equipment_ID, Batch_No
  - 分組欄位：Batch_No
  - 排序：主要 Batch_No
- 匯出結果（Excel）：
  - 分頁 1：Data Overview
  - 分頁 2：逐筆數據 (已排序)
  - 分頁 3：分組彙總數據 - 每個 Batch_No 的 Voltage/Current/Temperature 統計量（平均值等）
  - 分頁 4：統計信息（如勾選）

#### 5.4 圖表匯出

**PNG 圖檔**
- 高解析度點陣圖（預設 2x 縮放）
- 適合插入簡報或文件
- 白色背景

**SVG 向量圖**
- 可無限縮放而不失真
- 僅支援 Plotly 圖表（散點圖）
- 適合專業出版或後製

#### 5.5 下載說明

- 點擊「開始匯出」後，檔案會在後端生成
- 系統會自動開啟新視窗下載檔案
- 如未自動下載，請檢查瀏覽器的彈出視窗封鎖設定
- 匯出的檔案會暫存在伺服器（24小時後自動清理）

## 數據檢視模式詳解

系統提供 **2 種數據檢視模式**，在步驟 3 透過是否選擇分組欄位來決定。

### 模式 1：逐筆數據檢視（Flattened Data）

**觸發條件**：步驟 3 未選擇分組欄位

**特點**：
- 保留所有原始記錄，一筆一筆呈現
- 包含所有選定的數值指標和字串指標
- 可應用排序（主要/次要欄位）
- 數據列數 = 原始數據列數

**資料結構範例**：
```
| Source_File | Point_ID | Operator | Voltage | Current | Temperature |
|-------------|----------|----------|---------|---------|-------------|
| file1.csv   | P001     | John     | 5.2     | 0.15    | 25.3        |
| file1.csv   | P002     | John     | 5.3     | 0.16    | 25.5        |
| file2.csv   | P003     | Mary     | 4.9     | 0.14    | 26.1        |
```

**適用場景**：
- 需要完整的原始數據
- 進行詳細分析
- 匯出到 Minitab、MATLAB 等工具進行進一步處理
- 需要查看每一筆測試記錄的詳細資訊

### 模式 2：分組彙總檢視（Grouped Data）

**觸發條件**：步驟 3 選擇一個或多個分組欄位

**特點**：
- 數據依選定欄位分組
- 每組顯示數值指標的統計量（平均值、計數、最小值、最大值、總和）
- 數據列數 = 分組數量
- 自動計算每組的 totalCount（該組的數據筆數）

**資料結構範例**（按 Batch_No 分組）：
```
| Batch_No | Voltage（平均） | Current（平均） | Temperature（平均） | totalCount |
|----------|-----------------|-----------------|---------------------|------------|
| B001     | 5.25            | 0.155           | 25.4                | 2          |
| B002     | 4.90            | 0.140           | 26.1                | 1          |
```

**資料結構範例**（按 Batch_No + Operator 分組）：
```
| Batch_No | Operator | Voltage（平均） | Current（平均） | totalCount |
|----------|----------|-----------------|-----------------|------------|
| B001     | John     | 5.25            | 0.155           | 2          |
| B002     | Mary     | 4.90            | 0.140           | 1          |
```

**適用場景**：
- 趨勢分析（按時間、批次、設備等）
- 比較不同群組的表現
- 產生摘要報告
- 減少數據量，聚焦於整體趨勢

**特殊情況**：
- 如果分組欄位包含 `Point_ID`，等同於逐筆資料（每筆是獨立分組）

## 圖表功能說明

### 圖表引擎選擇

- **Plotly.js**：用於散點圖（Scatter Plot）
  - 優點：互動性強、支援 3D、可縮放
  - 支援 SVG 向量圖匯出
- **Chart.js**：用於折線圖和長條圖
  - 優點：輕量、渲染快速
  - 僅支援 PNG 點陣圖匯出

### 圖表資料來源

- 圖表**總是使用逐筆數據**（flattened data）進行繪製
- 即使步驟 3 選擇了分組欄位，圖表仍會顯示原始數據點
- 這確保圖表能顯示完整的數據分佈，而不是只有統計摘要

### 軸選項限制

- **數值軸**：只能選擇步驟 3 選定的數值指標
- **類別軸**：只能選擇步驟 3 選定的字串指標
- 這確保圖表配置與數據設定一致，避免選項混亂

### 圖例分組功能

圖例分組允許您將數據依某個字串欄位分組，以不同顏色或標記顯示：

**散點圖範例**：
- X 軸：Location_X（數值）
- Y 軸：Voltage（數值）
- 圖例分組：Batch_No（字串）
- 效果：不同批次的點會以不同顏色顯示

**折線圖範例**：
- X 軸：Point_ID（字串）
- Y 軸：Temperature（數值）
- 圖例分組：Operator（字串）
- 效果：每個操作員的數據會繪製成一條獨立的線

## 匯出功能

### 匯出檔案命名規則

系統會自動生成檔名，格式為：
- 數據匯出：`analysis_data_YYYYMMDDTHHMMSS`
- 圖表匯出：`chart_FORMAT_YYYYMMDDTHHMMSS`

範例：
- `analysis_data_20250122T143025.xlsx`
- `chart_png_20250122T143530.png`

您可以在匯出對話框中自訂檔名（不含副檔名）。

### Excel 分頁說明

每個分頁的用途：

1. **Data Overview（資料總覽）**
   - 快速了解數據整體狀況
   - 檢查來源檔案和批次資訊
   - 查看基本統計數據

2. **逐筆數據**
   - 完整的數據清單（含排序）
   - 用於詳細分析或匯入其他工具

3. **分組彙總數據**（可選）
   - 趨勢分析和摘要
   - 快速比較不同群組

4. **統計信息**（可選）
   - 每個欄位的詳細統計資訊
   - 缺失值、唯一值數量等

### CSV 格式說明

CSV 檔案使用區塊分隔：
- 每個區塊以 `=== 標題 ===` 開頭
- 區塊之間用空行分隔
- 使用 UTF-8 with BOM 編碼，確保 Excel 正確顯示中文

## 常見問題 FAQ

### Q1: 為什麼我的圖表 X 軸選項很少？

**答**：圖表的 X 軸和 Y 軸選項只會顯示您在步驟 3「資料參數設定」中選擇的指標。如果選項太少：
1. 返回步驟 3
2. 確認已選擇需要的數值指標和字串指標
3. 重新進入步驟 4 配置圖表

### Q2: 匯出的 Excel 檔案為什麼有這麼多分頁？

**答**：系統會自動包含所有相關數據：
- Data Overview（總是有）
- 逐筆數據（總是有）
- 分組彙總（如果步驟 3 有選擇分組欄位）
- 統計信息（如果勾選「包含摘要統計」）

這確保您擁有完整的數據和分析結果，無需多次匯出。

### Q3: 排序功能的作用是什麼？

**答**：排序功能會影響：
1. 步驟 3 的資料預覽順序
2. 匯出的數據順序（Excel 和 CSV）
3. 不影響圖表顯示（圖表保持原始順序）

排序對於匯出到 Excel 進行後續分析特別有用。

### Q4: 分組檢視和逐筆檢視有什麼區別？

**答**：
- **逐筆檢視**（不選分組欄位）：保留所有原始數據，適合詳細分析
- **分組檢視**（選擇分組欄位）：產生統計摘要，適合趨勢分析

兩種模式的數據都會包含在匯出檔案中，您可以同時擁有詳細數據和摘要。

### Q5: CSV 檔案在 Excel 中開啟時中文顯示為亂碼怎麼辦？

**答**：系統已自動添加 UTF-8 BOM，大多數情況下 Excel 會正確顯示。如果仍有問題：
1. 使用 Excel 的「資料」→「從文字/CSV」匯入功能
2. 選擇檔案編碼為「65001: Unicode (UTF-8)」
3. 或直接使用 Excel 格式（.xlsx）匯出，不會有此問題

### Q6: 我可以跳過圖表繪製直接匯出數據嗎？

**答**：可以！步驟 4「圖表配置與預覽」是可選的。如果您只需要整理數據而不需要視覺化，可以直接點擊「下一步」跳過，進入步驟 5 匯出。

### Q7: 為什麼數值指標和字串指標要分開選擇？

**答**：這個設計有幾個原因：
1. 明確區分數值型數據（用於計算）和類別型數據（用於分組/標識）
2. 字串指標會影響圖表配置選項（X 軸、圖例分組）
3. 分組彙總只對數值指標計算統計量
4. 提供更精確的數據控制

### Q8: 統計信息包含哪些內容？

**答**：包括：
- 總行數、總列數
- 每個欄位的平均值、中位數、最小值、最大值（數值型）
- 缺失值數量
- 唯一值數量

這些資訊對於數據品質檢查和初步分析很有幫助。

## 最佳實踐

### 數據準備

1. **標準化欄位名稱**
   - 使用英文或簡短的中文
   - 避免特殊字元（如 `#`, `@`, `%`）
   - 使用底線代替空格（如 `Test_Result` 而非 `Test Result`）

2. **確保數據一致性**
   - 同一欄位的數據型別應一致
   - 日期格式統一
   - 類別值使用一致的大小寫和拼寫

3. **包含必要的識別欄位**
   - 建議包含 `Point_ID` 或類似的唯一識別碼
   - 包含 `Batch_No` 或時間戳記以追蹤數據來源

### 數據清理

1. **優先處理缺失值**
   - 先檢查缺失值比例
   - 如果比例很小（<5%），考慮刪除
   - 如果比例較大，考慮插值或填充

2. **謹慎處理異常值**
   - 異常值不一定是錯誤，可能是重要發現
   - 檢查異常值的來源和原因
   - 必要時保留異常值並標記

3. **分批清理**
   - 一次只執行一種清理操作
   - 檢查預覽結果後再進行下一步
   - 避免過度清理導致數據失真

### 參數設定

1. **數值指標選擇**
   - 只選擇需要分析的數值欄位
   - 避免選擇無意義的數值欄位（如 ID 號碼）

2. **字串指標選擇**
   - 選擇對分析有意義的分類欄位
   - 通常包括設備、批次、操作員等

3. **分組策略**
   - 逐筆檢視：適合初步探索和詳細分析
   - 分組檢視：適合趨勢分析和比較

4. **排序設定**
   - 主要排序選擇最重要的分類欄位（如批次號）
   - 次要排序選擇數值欄位或細分類欄位

### 圖表繪製

1. **選擇適合的圖表類型**
   - 觀察相關性 → 散點圖
   - 觀察趨勢 → 折線圖
   - 比較大小 → 長條圖

2. **合理使用圖例分組**
   - 分組數量建議不超過 10 個（太多會難以區分）
   - 選擇有意義的分組欄位（如批次、設備、結果）

3. **圖表標題**
   - 使用描述性標題（如「各批次電壓分佈」）
   - 避免使用技術術語或縮寫

### 數據匯出

1. **選擇適合的格式**
   - 需要多分頁組織 → Excel
   - 需要與其他工具相容 → CSV
   - 兩種格式都匯出以備份

2. **檔名管理**
   - 使用描述性檔名（如 `電壓測試_2025Q1_批次分析`）
   - 系統會自動加上時間戳記

3. **勾選統計信息**
   - 建議預設勾選，提供完整的分析資料
   - 如果只需要原始數據，可取消勾選以減小檔案大小

### 工作流程建議

1. **第一次分析**
   - 使用逐筆檢視模式，不設排序
   - 先繪製散點圖探索數據分佈
   - 檢查是否有異常值或趨勢

2. **深入分析**
   - 使用分組檢視，按關鍵欄位分組
   - 繪製折線圖或長條圖比較各組
   - 設定排序以便匯出

3. **最終報告**
   - 匯出 Excel 格式（包含統計信息）
   - 匯出圖表為 PNG（插入報告）
   - 保留 CSV 備份供其他工具使用
